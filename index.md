# 📊 IOI-LottoLab - Analyze lottery trends with data science

IOI-LottoLab allows you to study lottery patterns based on historical data. This software provides tools to test different number strategies, view results on a dashboard, and maintain a record of your research. It uses machine learning models to help you understand trends within lottery data.

## 🚀 Setting up the application

Follow these steps to launch the software for the first time:

1. Locate the shortcut named "IOI-LottoLab" on your desktop or in your start menu.
2. Select the icon to open the main window.
3. The software will perform a check for local data. If the folder is empty, the application will prompt you to download the latest lottery history.
4. Select "Download Data" to synchronize the records of past drawings.
5. Once the progress bar fills, the software is ready for use.

## 📈 Understanding the features

### Audit ledger
The software keeps a record of every calculation and test you run. You can view these logs anytime. This feature ensures that you know which settings led to a specific result.

### Backtesting engine
This tool recreates past lottery drawings. You can test your strategy against historical outcomes to see how it would have performed if you used it in the past. It offers a way to verify if your strategy relies on actual patterns or just luck.

### Dashboard
The dashboard displays your research results in charts and graphs. It shows frequency lists of numbers, time-based trends, and output from your machine learning models. You can filter the view by date range or specific number groups.

## 🛠 Troubleshooting common issues

If you encounter problems, follow these solutions:

- Application fails to start: Ensure your antivirus software is not blocking the program. Some security settings block new applications by default.
- Data download errors: Verify your internet connection. If the connection remains stable, check if your firewall prevents the software from reaching the data server.
- Slow performance: Ensure your computer is not running many demanding programs at the same time. Close background applications to give the software more memory.
- Blank screen: If the dashboard does not load, try restarting the application. This forces the software to refresh its internal browser windows.

## 📋 Tips for better research

- Start with a small data range. Testing too many years of data at once takes time.
- Use the visual filters on the dashboard to spot repeating numbers.
- Label your strategy tests clearly so you can find them later in your audit log.
- Keep your data updated. Run the update tool once a week to include the latest lottery outcomes.

## 🔒 Privacy and security

The software runs locally on your machine. You do not need an account to use the features. Your research data stays on your hard drive, and the software sends no personal information to any server. The network connection is only for downloading public lottery results.
